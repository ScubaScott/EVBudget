# Changelog

One line per version, newest first. The longer, plain-language notes people see in the app live in `evbudget/releases.json`.

- **4.0** (2026-11-05): Bank sync through SimpleFIN, imports always go to a listed account, duplicate spotting across synced and file rows, and a friendlier make-a-rule box on the import screen.
- **3.7** (2026-11-02): Bills match payments by words (renamed payees no longer suggested again), price changes still link, link past payments from the bill form, review list for bills with too-specific bank text, and a prompt when a fixed bill's payment changes amount.
- **3.6** (2026-11-02): Accounts page and account filter, Start/End dates moved up beside the presets, PDF statements from any bank (Chase first), Synchrony statement credits, import flags rows already saved under another account, select-all on import review.
- **3.5** (2026-11-01): Spending and Income merged, setup walkthrough, Rules page with a review-before-apply screen, in-app updates, What's new and feedback, bulk update in one window, clearer What's new.
