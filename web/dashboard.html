Classification rules
Rules decide each row's kind, envelope and payee during import. Rules marked Just me apply only to this budget and run first; rules marked Everyone are shared by all budgets.
For a rename, the matched part is replaced; use \1 (or $1) for the first (group) you captured. Example: SQ\s?\*\s?(.*) → \1 turns SQ *Vendor into Vendor, and (.*?)\s*#\d+$ → \1 turns Store #3456 into Store. Pattern renames chain, so both can apply to one payee.
